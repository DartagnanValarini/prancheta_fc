# instagram-posts

Branch órfã (sem histórico do jogo) que guarda as imagens publicadas na @catimbafcbr e o histórico de posts.
O Instagram busca as imagens pela URL raw desta branch:
https://raw.githubusercontent.com/DartagnanValarini/prancheta_fc/instagram-posts/<AAAA-MM-DD-slug>/NN.jpg

As ferramentas (templates, render, prints, skill) ficam na main, em social/.
Pode apagar esta branch quando quiser: os posts já publicados continuam no Instagram.
